# Skuld Battery Agent

Agente especializado em monitoramento de bateria para Android via Termux.

## Funcionalidades

- ✅ Monitoramento contínuo da bateria
- ✅ Detecção inteligente de mudanças
- ✅ Prioridades dinâmicas baseadas no nível
- ✅ Automação de notificações (via Core)
- ✅ Tratamento robusto de erros
- ✅ Logging detalhado com níveis
- ✅ Configuração via linha de comando
